README - Taskcli
Taskcli

Taskcli is a command-line interface (CLI) task tracking application developed in C. It allows you to manage your daily tasks efficiently directly from your terminal.

Inspiration
This project was inspired by the Task Tracker project from roadmap.sh, but modified and implemented in C according to my own design and workflow preferences.

Features
- Add, update, and delete tasks
- Mark tasks as in-progress or done
- List tasks by status (all, todo, in-progress, done)
- Lightweight and fast, built in C
